# Flavor Isle Pulse

All Pulse work lives here: pre-plans, builds, correctives and BuilderReports.

Pulse is the staff app (Base44 app `6a0079b09d458a77c24ffba5`, live at pulse.flavor-isle.com). It is NOT the Flavor Isle customer site, which stays in `flavorisle/flavor-isle`.

Process for every change: proposal by email, approved, exhaustive pre-plan posted here as an issue, then the builder, then the BuilderReport verified against the pre-plan before anything is called done.
